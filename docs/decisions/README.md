# Architecture Decision Records (ADRs)

Los ADRs documentan las decisiones técnicas significativas del proyecto: qué se decidió, por qué y cuáles son los trade-offs.

## ¿Cómo usar esto?

- **Leer:** cada archivo es una decisión independiente y auto-contenida
- **Nueva decisión:** copia `ADR-000-template.md`, incrementa el número y abre un PR
- **Decisión obsoleta:** cambia el estado a `deprecado` o `reemplazado por ADR-XXX`
